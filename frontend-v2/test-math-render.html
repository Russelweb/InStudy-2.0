Example 2: What the AI should output

Consider the function $f(x) = \sin(x^2)$. To compute its derivative using the chain rule:

$$f'(x) = \cos(x^2) \cdot 2x$$

Using the chain rule formula:
$$\frac{d}{dx}[f(g(x))] = f'(g(x)) \cdot g'(x)$$

Where:
- $g(x) = x^2$
- $g'(x) = 2x$
- $f(u) = \sin(u)$
- $f'(u) = \cos(u)$

Therefore: $f'(x) = \cos(x^2) \cdot 2x$
