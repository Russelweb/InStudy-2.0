# Educational Images Library

This directory contains curated educational images for flashcards.

## Structure
- `science/` - Science-related images (biology, chemistry, physics)
- `math/` - Mathematics images (geometry, algebra, calculus)
- `technology/` - Computer science and technology images
- `history/` - Historical images and artifacts
- `language/` - Language and literature images
- `general/` - General educational icons and symbols

## Image Requirements
- Format: PNG or JPG
- Size: 200x200 pixels (square)
- Quality: High resolution, clear visibility
- Style: Educational, professional, appropriate for learning

## Naming Convention
- Use descriptive names: `dna_structure.png`, `calculus_symbol.png`
- No spaces, use underscores
- Include subject prefix when helpful: `bio_cell.png`, `math_graph.png`
